# 온톨로지 준비도 체크리스트

이 문서는 A안 학습 경로 배치 전에 확인하는 기준선이다. `부분 충족`과 `미충족` 항목은 데이터로 자동 보완하거나 통과로 해석하지 않는다.

- [ ] **개체 — 부분 충족**
  - 확인: 정본 이름, 안정 ID, 별칭, 개체 유형, 유형 판별 기준, 중복 판정 규칙
  - 근거: `ontology-schema.js`는 개체 유형과 필수 속성, `ontology-utils.js`는 전역 ID 중복을 정의한다. 159개 용어의 안정 ID·별칭·유형 판별은 아직 등록되지 않았다.

- [ ] **속성 — 부분 충족**
  - 확인: 이름, 뜻, 자료형, 필수 여부, 허용값, 정본 출처, 결측 처리
  - 근거: `ontology-schema.js`의 `PROPERTY_DEFINITIONS`가 자료형·필수 여부·소유 파일을 고정한다. 실제 159개 값의 결측 처리는 다음 데이터 등록과 감사에서 확인한다.

- [ ] **관계 — 부분 충족**
  - 확인: 이름, 뜻, domain, range, 방향, 대칭성, 다중성, 순환, 금지 조합
  - 근거: `ontology-schema.js`의 10개 관계 사전과 `ontology-utils.js`의 domain/range·자기 참조·선행 순환 검증. 개별 관계의 금지 조합과 승인 데이터는 아직 없다.

- [ ] **근거 — 부분 충족**
  - 확인: 허용 출처, 검토 상태, 검토 책임자, 변경 이력
  - 근거: `ontology-schema.js`의 상태 목록 및 `ontology-utils.js`의 REVIEWED 근거·`content-owner`·검토 기록 ID·ISO 검토일 검증. 허용 출처 목록과 변경 이력 데이터는 아직 없다.

- [ ] **질문 — 부분 충족**
  - 확인: 다섯 competency question과 각 질문의 화면 행동
  - 근거: `docs/superpowers/plans/20260902_product_implementation-plan_ontology-learning-map.md`의 고정 질문. 화면 행동은 학습 지도 구현 전이므로 아직 검증할 수 없다.
  - 질문과 예정 화면 행동:
    1. 선행 용어는 무엇인가? → 선택 용어의 선행 학습 흐름을 표시한다.
    2. 혼동하기 쉬운 용어와 차이는 무엇인가? → 비교 관계와 근거를 표시한다.
    3. 함께 사용하는 도구·환경과 이유는 무엇인가? → 관계 대상과 근거를 표시한다.
    4. 개발 목표별 학습 순서는 무엇인가? → 학습 경로의 순서와 배치 근거를 표시한다.
    5. 이 연결의 근거는 무엇인가? → REVIEWED 관계의 출처와 검토 기록을 표시한다.

- [ ] **품질 — 부분 충족**
  - 확인: 누락, 중복, 고립, 약한 경로 배치, 모순 관계 측정법
  - 근거: `ontology-utils.js`가 ID 중복, 주제·경로 누락, 잘못된 참조, 선행 순환을 검출한다. 고립·약한 배치·관계 모순의 전체 감사 기준선은 이후 `scripts/audit-ontology-readiness.js`에서 측정한다.
