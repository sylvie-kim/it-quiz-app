# 초보자용 용어 사전 구현 검토

승인된 「버튼 하나에, 세 가지 역할」 시안을 학습지도에 통합하고, 이름·뜻을 찾는 화면을 용어 검색으로 분리했다. 제품 첫 페이지는 퀴즈다. 학습지도에서는 전체 6단계와 15개 경로를 기본 골격으로 보여주고, 각 경로 안에서 정의·체험·퀴즈로 연결한다. 159개를 30초 안에 배우게 한다는 뜻은 아니다.

## 구현한 동작

- 용어 검색 화면 맨 위에 검색창을 배치. 이름·별칭·정의 검색, 한 글자 검색, 빈 결과, 초기화 지원.
- HTML 구조 → CSS 꾸미기 → JavaScript 클릭 반응을 같은 버튼으로 체험. 확인 문제에서 정오답 설명 제공.
- 기본으로 펼쳐진 6단계 전체 지도에서 15개 학습 경로를 고르고, 각 경로의 용어와 해당 경로 퀴즈로 이동.
- 검색 결과와 전체 목록의 159개 용어에서 원래 정의, 학습 위치, 근거가 있는 기존 REVIEWED 관계 확인.
- 관계 없는 용어에는 확인된 연결이 없다고 표시. 학습 경로 소속으로 새 의미 관계를 만들지 않음.
- 각 역할에 한 문장 정의를 먼저 표시하고 버튼 예시를 뒤에 배치. 좁은 화면에서는 정의가 읽히도록 세 역할을 세로로 배치. 기존 다크·라이트 테마 토큰 사용. 모달 닫기와 경로 이동의 키보드 초점 복구.
- 기존 전체 연결 지도는 학습지도 안의 관계망 상세 화면으로 연결하고, 관리용 구조 진단과 배치 평가는 학습자 화면에서 제거. 영상·3D 렌더링은 첫 화면의 필수 의존성이 아님.

## 정의를 먼저 보여주는 교정

사용자 검토 후 HTML·CSS·JavaScript의 한 문장 정의를 첫 화면에 항상 표시했다. 버튼 설명은 「이 버튼에서는」으로 구분한다. 전체 지도에서 경로를 펼치면 각 용어의 원래 정의를 바로 읽을 수 있으며, 추가 클릭은 학습 위치·관계 확인에만 사용한다. 기존 정의 데이터는 변경하지 않는다.

## 이름과 이동에서 혼동되는 요소 점검

| 발견한 혼동 | 적용한 변경 |
|---|---|
| 용어 사전에도 학습 화면이 있고 별도 학습 지도도 있음 | 상단 퀴즈 / 학습지도 / 용어검색 순서로 통일. 첫 진입은 퀴즈, 메뉴의 159 숫자는 제거 |
| 정의·예시·경로를 어디서 읽을지 불명확 | 학습지도에서 모두 제공. 검색은 이름·별칭·뜻과 전체 정의 목록에 집중 |
| 예시의 시작하기가 실제 시작 버튼처럼 보임 | 예시 버튼으로 명시 |
| 6개 학습 단계가 선택 가능한지 불분명 | 모두 실제 경로 선택 버튼으로 연결 |
| 경로를 골라도 입문 체험이 계속 앞에 보임 | 전체 지도를 기본으로 표시. 웹페이지 경로에서 정의를 먼저 읽고 버튼 체험을 열기. 정의 목록·전체 지도 복귀 제공 |
| 관계망 버튼이 다시 경로 목록을 엶 | 관계망 상세에서 연결 관계 화면을 바로 선택 |
| 관계망에 내부 개선 진단·실험 평가가 노출됨 | 학습자 화면에서 제거, 원본 분석 코드·데이터 보존 |
| 이동해도 현재 탭·주소·뒤로 가기가 일치하지 않음 | 현재 메뉴 강조, #learn/#search/#quiz/#connections 경로와 브라우저 뒤로 가기 연동 |
| 퀴즈 중 검색으로 이동하면 문제를 놓침 | 모든 퀴즈 유형에서 검색 창을 겹쳐 열기. 답안 입력이 있을 때만 답안에 넣기 노출 |
| 학습지도로 이동한 뒤 퀴즈 탭에서 문제 선택 화면으로 돌아감 | 현재 세션의 풀던 문제·결과 화면 복귀 |

브라우저에서 검색 「접점」 → Interface 상세 → 정보 연결 경로 → 뒤로 가기 후 검색어 보존, 해당 경로 퀴즈 1/7 유지, 검색 창 닫기, 학습지도 왕복 후 퀴즈 복귀를 확인했다. 새로고침 후 퀴즈 진행 상태까지 영구 저장하는 기능은 이번 범위에 포함하지 않았다.

## 기본 화면 교정

퀴즈가 첫 페이지이며 상단 메뉴도 퀴즈 → 학습지도 → 용어검색 순서다. 학습지도의 기본 골격은 앞서 제안한 6단계 전체 지도로 해석해 구성했다. 버튼 체험은 화면 만들기 → 웹페이지의 구조와 동작 경로 안에 배치한다. 제품 첫 진입, 메뉴 순서, 전체 지도 → 정의 → 체험 → 정의 목록 → 전체 지도 왕복을 확인했다.

## 검증 결과

- Node 전체 테스트 156개 통과. 6단계/15경로/159용어 누락 없음, 단계 전환과 채점, 근거 없는 관계 제외 검증 추가.
- 브라우저 실동작: 세 단계 전환, 클릭 인사말, 오답/정답, 검색 「접점」→ Interface, 「앱」 한 글자 검색, 검색 결과 없음, 검색 초기화, 전체 159개 목록/카테고리 정렬, 용어 상세→경로 이동, 해당 API 경로 객관식 7문제 시작 확인.
- 실제 CSS 뷰포트 320/390/768/1280px에서 문서 가로 넘침 없음. 좁은 화면과 데스크톱, 라이트·다크 화면 확인. 모달에서 경로로 이동하면 경로 제목에 초점이 놓이는 것 확인.
- 최종 브라우저 오류 로그 없음. 정적 자산 버전 20260909.5로 통일.
- 실제 초보자 5명의 첫 노출 30초 이해 검사는 미실시. 사용성 개선 효과는 아직 검증 전이다.

## 저장소와 배포 상태

- 기반: codex/term-learning-map, 구현 전 HEAD 186d94b. 기존 미추적 도구 출력은 수정·stage하지 않음.
- 변경 소유 범위: app.js, index.html, glossary-learning.js/css, learning-map.js, 관련 테스트 3개, 이 검토 기록.
- 원격 저장소는 public. GitHub Pages는 main 루트를 직접 배포하는 legacy 방식이며 현재 서비스는 built 상태로 조회됨.
- Express 추가 전에는 로컬 구현·검증·커밋까지만 진행했다. 이후 공개 배포를 승인받았으며 아래 릴리스 항목을 따른다.
- 공개 배포 승인을 받았으며 기존 작업 브랜치의 학습지도 변경까지 포함한 전체 차이를 검토한다. 기존 브랜치는 작업 시작 시 origin/main보다 33개 커밋 앞서 있었다.


## Express 추가 및 배포 승인 (2026-09-09)

- 사용자 요청: “용어에 Express 하나 추가해서, 너가 만든대로 배포해줘”. 현재 구현 전체의 공개 배포를 승인받았다.
- 기존 159개에 Express를 추가해 총 160개. 별칭 Express.js / 익스프레스, 프레임워크 분류, 백엔드·클라우드·인증 학습 경로와 퀴즈에 포함한다.
- 정의 근거: [Express 공식 문서](https://expressjs.com/). Node.js용 웹 프레임워크, 주소별 요청 처리와 공통 처리 기능을 초보자에게 설명한다. 기존 두 출처의 용어 수는 유지하고 별도 official-document 출처를 기록했다.
- 위 156개 테스트·159개 목록 기록은 Express 추가 전 검증 이력이다. 이번 릴리스는 정적 자산 버전 20260909.6을 사용한다.
- 공개 관계 화면의 직접 주소로 새로고침해도 관계 보기로 복원하도록 수정했다.
- 배포는 전용 브랜치 push → PR 병합 → main 기반 GitHub Pages → 실제 공개 화면 확인 순서로 진행한다. 과거 감사 JSON은 당시 수치를 유지한다.

- Express 추가 후 Node 전체 테스트 157개 통과. 브라우저에서 첫 페이지 퀴즈, 익스프레스 검색 결과 1개, 백엔드 경로 정의, 관계망 직접 접속과 오류 로그 없음 확인.
- 공개본에서 개인 로컬 경로를 제외하며, 개발 이력에 남은 경로도 공개하지 않도록 최종 변경을 별도 릴리스 브랜치에 한 커밋으로 묶는다.
