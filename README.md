# IT Quiz (IT 용어 퀴즈)
**A vocabulary quiz for people starting vibe coding — learn the terms, and see right away why an answer is wrong.**

- Try it: https://sylvie-kim.github.io/it-quiz-app/
- Features: quizzes, a searchable glossary, and a learning map that shows how terms connect
- Built with plain HTML/CSS/JavaScript — designed and built with AI coding agents
- Tests: answer validation, answer-leak, and color-contrast checks (`test/`)
